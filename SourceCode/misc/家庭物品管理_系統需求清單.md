家庭庫存管理系統 (Anti-gravity Vibe coding) 需求規格說明書
1. 系統架構與環境設定
• 使用者範疇:

  • 系統以「家庭」為單位進行資料隔離。

  • 支援單一家庭 4 至 6 名成員共用同一庫存資料帳號。

  • 架構具備未來擴展至多個家庭的彈性。

• 前端開發: 採用 Flutter 進行跨平台行動端應用程式開發。

• 後端開發: 使用 Python 處理伺服器端邏輯，並配合 `.env` 環境變數管理敏感資訊（如 username, password, connection string 等）。

• 儲存設定:

  • 資料庫使用 PostgreSQL（本機以 container 測試，上線後部署於雲端平台）。

  • 檔案／照片儲存獨立於資料庫外，採用 Supabase 服務（免費方案提供 1GB 檔案儲存空間，不限 30 天試用期）。

  • 資料庫內部僅記錄照片在 Supabase 中的存取連結，不直接將影像存入資料庫。

• 連線需求:

  • 系統以在線狀態為基礎，不特別考慮離線運作機制。若偵偵測無網路或斷線，則系統暫時無法使用。

2. 物件資料與圖像規格
• 文字描述:

  • 欄位力求簡潔，僅記錄物品的通用概略名稱（例如：「螺絲起子」、「杯子」或「電鑽」）。

  • 不強制要求使用者填寫冗長複雜的詳細用途或描述。

• 照片規格:

  • 支援單一物件拍攝 1 至 4 張照片，以利多角度辨識。

• 壓縮與裁切機制:

  • 圖片在 Flutter 端上傳前進行裁切與壓縮處理。

  • 以長邊 450 像素為基準等比例縮放，短邊依當時拍照方向（橫拍或直拍）自動因應。

  • 目標將圖片檔案大小盡量壓縮在 3KB 至 5KB 之間，以節省儲存空間。

  • 拍攝介面附帶一個預設為「打勾」的 Checkbox 選項，用以控制尺寸壓縮功能。若使用者手動 untick 取消勾選，則該次拍照不上傳壓縮版本，以保留原始／高清晰度照片。

3. 空間階層與 QR Code 標籤
• 空間命名與階層:

  • 支援居家空間的細部編號管理，例如「廚房」內的特定抽屜或「車庫」的特定隔層。 並且拍攝一到三張照片， 以視覺方式讓使用者明確知道這儲存空間在家庭中的實際位置。

• QR Code 標籤生成:

  • 系統提供 QR Code 生成與列印介面，可連接使用者的 Brother 熱感應印表機。

  • 標籤可隨意黏貼於收納櫃外側或抽屜內側，供手機鏡頭隨時掃描。

• 標籤內容與尺寸:

  • 每個 QR Code 掃描後顯示的內容僅包含「物品名稱」與系統生成的「物品編號（流水號）」。

  • 資訊字串長度嚴格限制在 80 個字元以內，以確保 QR Code 圖案不會過於複雜且容易辨識。

  • 實體 QR Code 標籤的列印／實際尺寸規格至少為 2 公分 × 2 公分，以確保手機鏡頭能快速對焦讀取。

4. 借還狀態與活動記錄 (Check-in/Check-out)
• 基本功能:

  • 每次取用或歸還物品時，需透過掃描 QR code 切換狀態。

  • 系統會記錄當次活動是由家庭中的哪一位成員所操作。

• 重複操作處理:

  • 若遇到快速按壓或誤觸掃描導致的重複操作（例如連續按下兩次 check-out 按鈕），系統將採取「覆蓋前一次資料」的邏輯處理，避免產生重複紀錄。

• 歷史資料管理:

  • 物件的活動歷史紀錄（Lock history）設定為「保留一個月」。

  • 系統將寄生在 check-in／check-out 的機能之中，在每次使用者操作時自動觸發清理機制，刪除超過一個月的歷史活動紀錄，藉此維持資料庫輕便與高效率。

  • 刪除歷史紀錄的動作不會影響物件目前所在位置的最新狀態資料。

5. 進階搜尋與空間定位功能
• 物品定位（尋找遺失物）:

  • 當使用者在桌面上發現某個貼有 QR code 的物品，卻不知該將它放回哪一個空間時，可直接掃描物品的 QR code。

  • 系統會顯示該物品最後是由哪一位成員在某個櫃子所 chick-out 的歷史紀錄。

  • 使用者可據此順利將物品拿到該處或適合的儲存空間，並透過掃描儲存格 QR code 或按下 check-in 按鈕來完成歸位登記。

• 向量文字搜尋:

  • 支援使用 Python 向量／向量文字技術進行模糊搜尋。

  • 當使用者只有模糊印象（例如：尋找「電鑽」，但家中有好幾把放置在不同地方的電鑽）時，可透過文字輸入搜尋。

  • 搜尋結果會列出符合條件物品的縮圖，並清楚標示該物件目前的狀態（例如：已 check-in 在某處，或是已被某位成員 check-out）。
• 空間照片記錄: • 在新增、管理、修改或刪除儲存空間時，允許使用者拍攝 1 到 3 張照片，用以說明該儲存空間（櫃子）在家庭中的真實物理位置。
